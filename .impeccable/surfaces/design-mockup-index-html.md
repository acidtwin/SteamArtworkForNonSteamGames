# Main window (mockup)

Mode: Operate. Build path: code-led (Operate surface; no image generation).
Audience: Linux Steam users with non-Steam shortcuts, desktop and Steam Deck desktop mode (1280×800). Job: fill blank library art in one click, then swap individual pieces judged in context. Flows and states: design/architecture.md.

## Direction contract

THESIS: The window is a Steam library page that edits itself. It refuses the category default of a grid of equal thumbnail boxes with "Change" buttons.
OWN-WORLD: Steam desktop client language, pinned by the user: deep blue-grey ground (#171a21 / #1b2838 family), slate panels, pale grey-blue text, Steam blue (#1a9fff) for selection and focus, the client's green for the single primary action. Sans UI face, uppercase tracked section labels, low radii, no Valve marks.
STORY: The user sees their own games with coverage, clicks "Get artwork for N games", watches tiles fill, then opens a game and swaps a banner while seeing exactly how Steam will show it.
FIRST VIEWPORT: Header (account, coverage count, green primary action). Left: searchable game list with five coverage dots per row. Right: game title with "Matched to" line, then the Steam-style preview (banner with logo, cover, wide cover, icon) taking most of the pane; option tray slides up under it when a slot is chosen.
FORM: Pinned by user (Steam client style); concept roll skipped. seed: none (unavailable)
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
